2. ENDPOINT & PAYLOAD KEY MATRIX (NEXT.JS WEB <-> NESTJS BACKEND)
--------------------------------------------------------------------------------
1. Authentication:
   - Endpoint: POST /api/v1/auth/login & POST /api/v1/auth/register
   - Body: { email, password, role: "CITIZEN" | "CONTROLLER" }
   - Response: { accessToken, refreshToken, user: { id, email, role } }

2. Citizen Complaint Filing:
   - Endpoint: POST /api/v1/complaints
   - Header: Authorization: Bearer <token>
   - Body: { citizenName, phone, city, address, gstin, productName, 
             violationType, evidenceUrls: string[], statementOfFact }
   - Response: { complaintId: "CMP-2026-XXXX", status: "RECEIVED", createdAt }

3. Citizen Complaint Status Tracking:
   - Endpoint: GET /api/v1/complaints/:id/status
   - Response: { complaintId, status, inspectorAssigned, history: [...] }

4. Controller Dashboard Regional Analytics:
   - Endpoint: GET /api/v1/controller/dashboard/stats
   - Response: { totalInspections, totalViolations, totalRecovery, 
                 repeatOffenderCount, cityBreakdown: [...] }

5. Controller Compounding Action / Notice Approval:
   - Endpoint: POST /api/v1/controller/compounding/:id/action
   - Body: { action: "APPROVE" | "REJECT" | "ESCALATE", comments: string }
   - Response: { noticeId, newStatus: "COMPOUNDED" | "PROSECUTION", updatedAt }

6. Multi-Tier Supply Chain Traceability (Neo4j Graph):
   - Endpoint: GET /api/v1/supply-chain/trace/:gstin
   - Response: { gstin, businessName, nodes: [...], links: [...] }
